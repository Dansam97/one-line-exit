A one-line resignation letter for the make.fun bounty "The One-Line Exit": after nine years of keeping the place running, an IT/operations lifer resigns for the only maintenance window they still believe in — their own. `main.py` writes the single line to `entry.txt` in the output directory, validating it against the 140-character gate before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
